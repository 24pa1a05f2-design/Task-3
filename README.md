# 📚 Task 3 – REST API

A simple REST API built using **Node.js and Express.js** to manage a list of books.

The API supports complete **CRUD operations**:

- GET – Read books
- POST – Add a new book
- PUT – Update a book
- DELETE – Delete a book

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API
- JSON
- Postman
- Git

- Visual Studio Code
